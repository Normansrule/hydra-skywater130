# GPU command set

GENERATED by `tools/isa/gen_gpu_isa.py` from `gpu_pkg.sv`. Do not edit.

This is a 2D tile renderer, not a shader engine: work arrives as a
command stream, one 64-bit payload per command. The stream may be
plaintext or encrypted — when encrypted, the payload is recovered as
`payload = enc_payload XOR AES(seed, ctr)[63:0]`, with the counter in
the upper 64 bits of each 128-bit entry.

## Payload layout

| bits | field |
|---|---|
| [63:56] | opcode |
| [55:52] | value (tile id / color) |
| [51:48] | x (0..15) |
| [47:43] | y (0..31) |
| [15:0] | misc (WAIT frames) |

## Commands

| opcode | name | meaning |
|---|---|---|
| `0x00` | `GPUCMD_NOP` | do nothing |
| `0x01` | `GPUCMD_CLEAR` | clear the board |
| `0x02` | `GPUCMD_SET_CELL` | write the tile at (x, y) with value |
| `0x03` | `GPUCMD_WAIT` | stall for `misc` frames |
| `0xFF` | `GPUCMD_END` | end of stream |
