# Instruction set

GENERATED by `tools/gen_isa_doc.py` from the RTL. Do not edit: run the
tool. `make isa-check` fails if this file and the sources disagree.

HYDRA-130 has no instruction stream of its own. Work is issued as a
**128-bit work descriptor** — one descriptor is one instruction — and the
dispatcher decides which engine executes it. Everything else is
configuration through the register map at the end of this document.

## The work descriptor: the instruction word

## Operation classes (`op_class`)

The class selects the work-volume formula the cost model evaluates; the
comment is that formula.

| value | name | work volume |
|---|---|---|
| 0 | `OPC_SCALAR` | W = M                     (control-flow heavy) |
| 1 | `OPC_ELEMENT` | W = M                     (a[i] op b[i]) |
| 2 | `OPC_REDUCE` | W = M                     (sum, max, argmax) |
| 3 | `OPC_GEMM` | W = 2*M*N*K |
| 4 | `OPC_CONV2D` | W = 2*M*N*Kh*Kw*Cin |
| 5 | `OPC_FFT` | W = 5*N*log2(N) |
| 6 | `OPC_NTT` | W = (N/2)*log2(N)*CBF |
| 7 | `OPC_CIPHER` | W = bytes * cycles_per_byte |
| 8 | `OPC_HASH` | W = blocks * cycles_per_block |

## Hints

`lat_hint` biases against setup cost; `pwr_hint` sets the weight on the
energy term.

| value | lat_hint | meaning |
|---|---|---|
| 0 | `LAT_THROUGHPUT` | maximize work per second, setup cost is fine |
| 1 | `LAT_BALANCED` |  |
| 2 | `LAT_LOW` | penalize setup cost heavily |
| 3 | `LAT_REALTIME` | hard deadline: pick the lowest worst-case latency |

| value | pwr_hint | meaning |
|---|---|---|
| 0 | `PWR_MAX` | LAMBDA = 0,  ignore energy entirely |
| 1 | `PWR_BALANCED` | LAMBDA = 1 |
| 2 | `PWR_LOW` | LAMBDA = 4 |
| 3 | `PWR_MIN` | LAMBDA = 16 |

## What each engine can execute

5 engines. An engine whose mask clears the descriptor's class or
data type is removed from the selection **before any cost is compared**:
capability is a hard gate, not a penalty. Masks are bit-per-value,
least significant bit = value 0.

| engine | | op classes it accepts | data types it accepts |
|---|---|---|---|
| 0 `CPU` | scalar RV32IMC_Zba pipeline | SCALAR, ELEMENT, REDUCE, GEMM, CONV2D, FFT, NTT, CIPHER, HASH | INT8, INT16, INT32, FP16, FP32 |
| 1 `SIMD` | 4-lane 32-bit vector unit | ELEMENT, REDUCE, GEMM, CONV2D, FFT | INT8, INT16, INT32, FP16, FP32 |
| 2 `TPU` | 16x16 INT8 output-stationary systolic array | GEMM, CONV2D | INT8, INT16 |
| 3 `NTT` | 8-butterfly number-theoretic transform engine | FFT, NTT | INT32, POLY_Q |
| 4 `CRYPTO` | AES / SHA / HMAC datapath | CIPHER, HASH | INT32 |

## Engine cost parameters

One 43-bit row per engine, writable at run time through the `PARAM`
register — this is what makes the dispatch policy tunable after tapeout.

| field | bits | meaning |
|---|---|---|
| `p_peak_log2` | 4 | [42:39]  |
| `t_setup` | 12 | [38:27]  |
| `bw_bytes_log2` | 4 | [26:23]  |
| `eps_op` | 8 | [22:15]  |
| `dtype_msk` | 6 | [14:9]  |
| `opc_msk` | 9 | [8:0]  |

Reset values:

| engine | p_peak_log2 | t_setup | bw_bytes_log2 | eps_op | dtype_msk | opc_msk |
|---|---|---|---|---|---|---|
| CPU | 0 | 0 | 2 | 80 | `011111` | `111111111` |
| SIMD | 3 | 8 | 4 | 20 | `011111` | `000111110` |
| TPU | 7 | 64 | 5 | 2 | `000011` | `000011000` |
| NTT | 5 | 32 | 4 | 8 | `100100` | `001100000` |
| CRYPTO | 4 | 16 | 4 | 4 | `000100` | `110000000` |

Cost is a 32-bit cycle count, saturating. The calibration factor
is Q2.6 per engine and op class, moved by measured completions.

## Host register map

Reached over SPI in the register personality (see README, pin tables).
Command byte is `{rw, addr[6:0]}`, `rw = 1` reads; data follows, most
significant byte first; writes commit at chip-select rise and only if
exactly the right number of bytes arrived.

| addr | name | bytes | access |
|---|---|---|---|
| 0x00 | `ID` | 4 | RO |
| 0x01 | `WD` | 16 | RW |
| 0x02 | `CTRL` | 1 | RW |
| 0x03 | `ACTION` | 1 | RW |
| 0x04 | `COMP` | 1 | RW |
| 0x05 | `STATUS` | 2 | RO |
| 0x06 | `RESULT` | 6 | RO |
| 0x07 | `LASTWD` | 16 | RO |
| 0x08 | `CALUPD` | 2 | RO |
| 0x09 | `BUSY` | 2 | RO |
| 0x0A | `FENCE` | 1 | RW |
| 0x0B | `PARAM` | 6 | RW |
| 0x0C | `GLOBAL` | 2 | RW |
| 0x0D | `INFO` | 1 | RO |

Unmapped addresses read as zero; writing one sets `FRAME_ERR`.
