# HYDRA-130 architecture

Generated by `tools/gen_site.py`; `make site-check` proves it still matches the
repository. Three views, kept apart on purpose (SkyWater 130 audit, 2026-10-11):
what one named build contains, what exists as checked IP, and what is planned.

## As built: ecp5-evn-mem (scheduler + memory-fed array)

Every module below is instantiated in `plans/ecp5-evn-mem.yaml`'s own source list; the
generator checks it. The CPU, vector, NTT and crypto slots are latency models.

```mermaid
flowchart LR
  host["Host<br/><small>PC, Python driver</small>"]
  bridge["Bridge<br/><small>UART to pins, memory</small>"]
  spi["SPI slave<br/><small>register map</small>"]
  regs["Registers<br/><small>the host map</small>"]
  feat["Features<br/><small>log2 work, intensity</small>"]
  cost["Cost engine<br/><small>one, walked over five</small>"]
  sel["Select<br/><small>argmin with margin</small>"]
  sb["Scoreboard<br/><small>tags, queue depth</small>"]
  cal["Calibrate<br/><small>measured vs predicted</small>"]
  xbar["Crossbar<br/><small>descriptor to engine</small>"]
  tpu["TPU, from memory<br/><small>4x4 INT8 array</small>"]
  models["Latency models<br/><small>CPU, SIMD, NTT, crypto</small>"]
  dma["Streamer<br/><small>banks to the array</small>"]
  bank["Scratchpad<br/><small>A, B, results</small>"]
  host -- bytes --> bridge
  bridge -- pins --> spi

  cal -- k --> cost
```

## IP library: built and checked, not all connected

| block | what | file | check |
|---|---|---|---|
| TPU array | 4x4 INT8 systolic array | `engines/tpu/rtl/tpu_top.sv` | `make tpu` |
| Vector unit | 4 x 32-bit lanes (not a GPU) | `engines/simd/rtl/simd_top.sv` | `make simd` |
| NTT | 4 Barrett butterflies, 3 moduli | `engines/ntt/rtl/ntt_top.sv` | `make ntt-moduli` |
| Vector unit, from memory | streamer and banks | `sys/rtl/hydra_engine_simd_dma.sv` | `make dma-simd` |
| NTT, from memory | memory format v1 | `sys/rtl/hydra_engine_ntt_dma.sv` | `make dma-ntt` |
| Test port | IEEE 1149.1 TAP, own clock | `dbg/rtl/hydra_jtag_tap.sv` | `make jtag` |
| Clock crossing | test port into the register map | `dbg/rtl/hydra_jtag_bridge.sv` | `make jtag-bridge` |
| Key vault | write and use, never read back | `sec/rtl/hydra_key_vault.sv` | `make keyvault` |
| Mailbox | lock, command, execute | `sec/rtl/hydra_mailbox.sv` | `make mailbox` |
| SHA-256 | padded in hardware | `sec/rtl/hydra_sha256_stream.sv` | `make sha256-stream` |
| Measurement | extend-only register | `sec/rtl/hydra_pcr.sv` | `make pcr` |
| Security ISA | Zknh + Xhydrasec unit | `isa/rtl/hydra_xsec_unit.sv` | `make xsec` |
| Pad multiplexer | OpenFrame pad ownership | `common/rtl/hydra_padmux.sv` | `make padmux` |
